The tools you actually need

ADB-powered controls for Android system settings, games, apps, optimization, and everyday device management.

ADB terminal

Run ADB shell commands with a built-in terminal and session management.

System tweaks

Adjust supported Android settings with concise explanations and restore controls.

Game profiles

Create per-game profiles for supported game modes, FPS, and resolution scaling.

App optimization

Run supported app optimization and ART compilation tasks for selected apps.

Debloat

Find common unwanted packages and manage supported apps for the current user.

Monitor & diagnostics

View useful device information such as memory, storage, temperature, and refresh rate.
